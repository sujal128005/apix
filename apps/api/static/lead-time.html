This is a price profile, not an elasticity, and not yet a measured premium. On first contact with real data the nearest window came back cheaper than the furthest — but the two compared different departure dates, one a Monday and one a Sunday, so the comparison is confounded. Measuring the last-minute premium properly needs the same departure date observed at different horizons, over several weeks. See docs/evidence/O9-lead-time-premium.md.

No causal elasticity is estimated. What is shown is the observed fare level at each booking horizon on a single collection date. Calling it elasticity would claim considerably more than the data supports, so the name is not used anywhere in APIx.
